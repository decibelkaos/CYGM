## 🔄 OAuth2 Authentication Flow

Here's how the authentication works (what still needs UI implementation):

```
1. User taps "Connect Dexcom" in CGM Settings
   ↓
2. Device generates auth URL using dexcom_get_auth_url()
   ↓
3. Display URL on screen for user to open on their phone
   ↓
4. User opens URL → Logs into Dexcom → Gets redirected with auth code
   ↓
5. User enters auth code into device (via LVGL keyboard)
   ↓
6. Device calls dexcom_exchange_code_for_token(code)
   ↓
7. Tokens saved to NVS automatically
   ↓
8. Device can now fetch glucose data!
```

## ⚡ Quick Integration Example

Here's a snippet showing how to integrate into your UI code:

```c
// Add to global variables section
#include "dexcom_api.h"

static lv_obj_t *glucose_value_label = NULL;
static lv_obj_t *glucose_trend_label = NULL;

// In app_main() after WiFi connects
dexcom_api_init();

// Button click handler for "Connect Dexcom"
static void connect_dexcom_clicked(lv_event_t *e) {
    char auth_url[512];
    dexcom_get_auth_url(auth_url, sizeof(auth_url));

    // Display auth_url to user
    ESP_LOGI("UI", "Auth URL: %s", auth_url);

    // Show auth code entry screen...
}

// After user enters auth code
static void submit_auth_code(const char *code) {
    esp_err_t err = dexcom_exchange_code_for_token(code);
    if (err == ESP_OK) {
        ESP_LOGI("UI", "Successfully authenticated!");
        // Update UI to show "Connected"
    } else {
        ESP_LOGE("UI", "Authentication failed");
        // Show error message
    }
}

// Periodic glucose fetch task
static void glucose_update_task(void *pvParameters) {
    while (1) {
        if (dexcom_is_authenticated()) {
            dexcom_glucose_t glucose;
            if (dexcom_fetch_glucose(&glucose) == ESP_OK && glucose.valid) {
                ESP_LOGI("GLUCOSE", "Value: %d mg/dL, Trend: %d",
                         glucose.value, glucose.trend);
                // Update UI labels...
            }
        }
        vTaskDelay(pdMS_TO_TICKS(5 * 60 * 1000));  // 5 minutes
    }
}
```
